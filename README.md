# Fieldwork

A fictional product catalog built with HTML, CSS and JavaScript.

## Run

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Open http://127.0.0.1:8000 in Chrome.

Light, Dark and System controls are included. Theme synchronization fixed and verified: System follows browser appearance, while manual light and dark selections are preserved. [issue #1](https://github.com/Subham-KRLX/Existing-ONE/issues/1).
