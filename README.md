# Fieldwork

A fictional product catalog built with HTML, CSS and JavaScript.

## Run

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Open http://127.0.0.1:8000 in Chrome.

Light, Dark and System controls are included. System synchronization repair and verification are pending: see [issue #1](https://github.com/Subham-KRLX/Existing-ONE/issues/1).

Baseline code and original CSS artwork were prepared with AI assistance before recording.
